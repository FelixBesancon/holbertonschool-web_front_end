# Web Front-End

This repository gathers my front-end projects completed during my training at Holberton School. It focuses on building strong foundations in HTML and CSS through semantic page structure, accessibility, validation, layout, and styling.

---

## Overview

The goal of this repository is to document my progression in front-end development and showcase practical projects built around clean, standards-compliant web pages.

---

## Topics covered

### `html_advanced`
An HTML-focused project dedicated to structuring a complete web page using semantic tags and proper document hierarchy, without styling.

### `CSS_advanced`
A CSS-focused project based on the Techium starter page, covering advanced styling concepts such as variables, layouts, pseudo-elements, animations, and responsive front-end structure.

---

## Technologies used

- HTML5
- CSS3
- W3C Validator
- Google Fonts
- Git & GitHub

## Requirements

Depending on the project, files were developed and tested with:
- Chrome 78.x
- W3C-compliant HTML and CSS
- Clean file structure and valid markup

---

## Skills developed

Through these projects, I worked on:
- Semantic HTML structure
- Page hierarchy and accessibility basics
- Tables, media, audio, video, and embedded content
- CSS variables and selectors
- Layout systems and responsive thinking
- Animations, transforms, and pseudo-elements
- Writing standards-compliant front-end code
