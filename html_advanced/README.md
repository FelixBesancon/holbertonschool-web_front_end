# Advanced CSS

This project focuses on styling the Techium homepage using advanced CSS concepts and front-end best practices.

---

## Description

The purpose of this project is to build a more complete and polished front-end page by applying modern CSS techniques to a provided HTML structure. It covers selectors, variables, layout systems, pseudo-classes, pseudo-elements, animations, transformations, and visual consistency across browsers.

The project uses the **Techium** starter HTML file and required assets stored in an `images/` directory.

---

## Learning objectives

- Use selectors, properties, and values correctly
- Understand the difference between block and inline styling
- Use CSS reset techniques for consistency
- Define and reuse CSS variables
- Understand inline, embedded, and external CSS
- Build layouts with float-based grid systems
- Use web fonts and SVG icons
- Work with pseudo-classes and pseudo-elements
- Create gradients, animations, and 2D/3D transforms
- Understand vendor prefixes and browser compatibility

---

## Technologies used

- HTML5
- CSS3
- Google Fonts
- W3C Validator

- A `README.md` file at the root of the project
